# Components and props

Every field takes: `name`, `label`, `id`, `model` (`false` ignores the bound model), `default`, `required`, `disabled`, `showLabel`, `showErrors`, `inline`, `inlineLabelClass`, `inlineInputClass`, `formGroupClass`, `help`. Text-like fields also take `placeholder`, `showPlaceholder`, `prepend`, `append`, `thaana`, `thaanaToggle`. Controlled use: `value` with `onChange` (inputs), `onValueChange` (number, select) or `onCheckedChange` (checkbox, radio).

| Blade                                                          | React                                                       | Key props                                                                                                                                                     |
| -------------------------------------------------------------- | ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `form`                                                         | `Form`                                                      | `model`, `action` (URL or Wayfinder), `method`, `files`, `errorBag`, `summary`, `form` (useForm), `onSubmit`, `onSuccess`, `preserveScroll`, `resetOnSuccess` |
| `@model`                                                       | `Model`                                                     | `model`                                                                                                                                                       |
| `text`, `email`, `password`, `url`, `tel`                      | `Text`, `Email`, `Password`, `Url`, `Tel`                   | `Url` adds `https://`; `Password` is never pre-filled                                                                                                         |
| `input`                                                        | `Input`                                                     | `type`                                                                                                                                                        |
| `number`, `latitude`, `longitude`                              | `Number`, `Latitude`, `Longitude`                           | `min`, `max`, `step`, `decimals`                                                                                                                              |
| `hidden`                                                       | `Hidden`                                                    | `value` (an array submits `name[]` per item)                                                                                                                  |
| `textarea`                                                     | `Textarea`                                                  | `rows` (3), `autoResize`, `wysiwyg`                                                                                                                           |
| `wysiwyg`                                                      | `Wysiwyg`                                                   | submits HTML; the editor comes from the adapter (`onuEditor`)                                                                                                 |
| `checkbox`                                                     | `Checkbox`                                                  | `value` (`1`), `children` (label beside the box), groups: `name="channels[]"`                                                                                 |
| `radio`                                                        | `Radio`                                                     | `value`, `children`                                                                                                                                           |
| `select`                                                       | `Select`                                                    | `options`, `relation`, `multiple`, `nameField`, `idField`, `excludeSyncField`, `syncFieldName`, `children` (`<option>`s)                                      |
| `select2`                                                      | `Select2`                                                   | `Select`'s props, `tags`, `allowClear`, `hideSearch`, `isAjax` + `ajaxUrl`, `child` / `parent` + `filterField`, `ajaxChild`, `fallback`, `minChars`           |
| `date`, `datetime`, `time`                                     | `Date`, `Datetime`, `Time`                                  | `min`, `max`; submit `yyyy-MM-dd`, `yyyy-MM-dd HH:mm:ss`, `HH:mm`                                                                                             |
| `file`, `file-upload`                                          | `File`, `FileUpload`                                        | `type` (`document`, `image`, …), `mimetypes`, `maxSize` (KB), `collection`, `conversion`, `multiple`, `onUploaded`                                            |
| `image`, `image-upload`                                        | `Image`, `ImageUpload`                                      | `width`, `height`, `circle`, `cover`, `aspectRatio`                                                                                                           |
| `map-input`                                                    | `MapInput`                                                  | `latName`, `lngName`, `enableRadius`, `enablePolygon`, `radiusUnit`                                                                                           |
| `conditional-wrapper`                                          | `ConditionalWrapper`                                        | `enableElem` (`#id` or name), `enableValue`, `hideFields`, `disable`, `enableCheckbox`                                                                        |
| `form-group`, `label`, `input-help`, `errors`, `error-summary` | `FormGroup`, `Label`, `InputHelp`, `Errors`, `ErrorSummary` | `Errors name firstOnly bag`                                                                                                                                   |
| `button`, `submit`, `link-button`, `button-group`              | `Button`, `Submit`, `LinkButton`, `ButtonGroup`             | `color` (`primary`, `danger`, `outline-secondary`, …), `size`, `startIcon`, `loading`; `LinkButton url`                                                       |
| `alert`, `card`, `modal`, `status`                             | `Alert`, `Card`, `Modal`, `Status`                          | `Alert type heading dismissible`; `Card title subtitle footer`; `Modal title trigger size`; `Status color label`                                              |
| `accordion`, `tabs`, `nav-tabs`                                | `Accordion`, `Tabs`, `NavTabs`                              | `Accordion id items`; `Tabs tabs active` + `TabsPane name`; `NavTabs tabs`                                                                                    |
| `text-entry`, `boolean-entry`, `infolist`                      | `TextEntry`, `BooleanEntry`, `Infolist`                     | `name` reads the bound model; `Infolist model title`                                                                                                          |
| `conditional-link`                                             | `ConditionalLink`                                           | `url`, `can` (with `FormsProvider authorize`), `showLink`                                                                                                     |

Options take Laravel's shapes: `{ id: "Label" }` (`pluck('name', 'id')`), a PHP list (values are indexes), ordered pairs `[[10, "Ten"]]`, records `[{ id, name }]` (`nameField`, `idField`), or `{ value, label }`.
